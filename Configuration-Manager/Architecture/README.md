# Microsoft Configuration Manager (SCCM/MECM)

## Overview

This section documents the implementation of Microsoft
System Center Configuration Manager (SCCM), also known
as Microsoft Configuration Manager.

## Objectives

- Centralized endpoint management.
- Application deployment.
- Windows software update management.
- Hardware inventory collection.
- Enterprise device administration.

## Documentation

This section covers the architecture, installation,
software deployment, updates, and hardware inventory.

## Environment

- Organization: Nile Bank (Lab Environment)
- Platform: Microsoft Configuration Manager
- Environment: Virtualized Enterprise Lab
